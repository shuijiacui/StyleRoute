## 3. 评分不是预设“最优答案”

先生成默认全局0.6结果，测得该图对的 `Q0/T0`。约束给定可接受风格统计偏离，搜索在这个可行范围里降低目标。没有预先指定某张最优图片或目标损失值。

### 3.1 独立评价网络

使用固定torchvision ImageNet VGG19评价权重，显式登记权重枚举/版本、层、预处理和指纹。网络冻结、`eval`、无梯度，准备一次内容特征、风格Gram与结构权重。

它与M4的AdaIN生成编码器分开封装，不能混用二者输入标准化。内容图与输出图保持空间对齐，固定尺寸；风格参考使用固定、记录过的评价尺寸。两者仍是相近VGG特征体系，指标偏好需要在报告中说明。

### 3.2 Q：结构代理损失

在评价网络relu3_1，取生成图与内容图逐位置通道均方差 `d(p)`。由原内容图的平滑梯度构造有界非负权重 `b(p)`，缩放到该特征尺寸：

```text
Q = Σ_p b(p) × d(p) / Σ_p b(p)
```

梯度算子、平滑、权重上下界、插值、归一化与零分母处理写入配置。原图权重不能随候选变化。Q是内容特征偏离，不是几何或语义真值。

### 3.3 T：风格统计损失

在relu1_1至relu4_1比较生成图与同一参考的归一化Gram矩阵，各层均方误差等权平均。建议明确采用 `G(F)=F·Fᵀ/(C×H×W)`，并固定层间平均口径；若选择其他归一化必须记录并全程一致。

风格与生成图空间尺寸可以不同，但通道与Gram定义一致。不能每个候选更换参考、裁剪或归一化以获得更低T。

### 3.4 S与J：协调和搜索目标

```text
S(a) = Σ_(i,j) w_ij × (a_i-a_j)^2 / Σ_(i,j) w_ij
J(a) = Q(a)/(Q0+δ) + λ × S(a)
```

无边或权重总和为零时S取0；`δ>0`和`λ≥0`固定并记录。Q/T/S/J分别报告，不能只交一个综合分数。

图或λ变化时J的含义随之变化，不能直接用各自J证明加权图优于无协调。跨表示或跨目标主要比较共同的Q/T、轮廓和开销；风险与普通局部搜索在固定目标下才直接比较同一J。

### 3.5 可行性与统一比较器

```text
L = (1+ε) × T0
violation(a) = max(0, (T(a)-L)/(T0+δ_T))
```

`ε`建议先试5%，在独立试运行图上检查后冻结；不是已验证最佳值。记录损失小量与浮点容差，用同一比较器处理全部方法。

可行解优先；不可行状态先按超限量排序，再按J排序；可行状态按J比较。只接受超过已冻结容差的严格改善，持平不循环移动。默认状态天然满足相对T0上限，是保底可行解。非有限分数应作为明确失败处理，不能偷偷记成更优值。

## 4. 搜索空间与风险定义

- 状态是N个区域强度 `a=(a0,...,aN-1)`，每项来自 `{0.3,0.6,0.9}`。
- 初始全部0.6；动作只修改一个区域到另外一档，最多2N个单步邻居。
- 不穷举3^N组合，也不搜索生成网络权重。风格尺寸、后处理与区域设置在主实验固定。
- 状态缓存宜使用离散档位索引元组作为键，避免浮点元组表示差异；缓存身份还须绑定图对、区域与评分配置。

风险使用与J一致的结构和协调贡献，而非凭区域面积或人工喜好排序。建议把Q的空间贡献按重采样并归一化的区域软权重分配，得到 `q_i`，使 `Σq_i≈Q`；每条协调边的贡献对两端各分一半，得到 `s_i`，使 `Σs_i≈S`。

```text
risk_i = q_i/(Q0+δ) + λ × s_i
```

按风险降序、并列按区域ID。说明风险与评价特征尺寸对齐的方法，并验证贡献求和。若采用其他分摊规则，先冻结再比较。风险大不代表该区域一定容易改善；修改后必须重新评分全图，不能假设各区域相互独立。

## 5. 可直接落实的局部搜索流程

1. **初始化**：评价给定默认图，建立当前状态、最佳可行档案和缓存；默认状态计入一次不同状态预算。M4已生成时不重复解码，但日志要表明该生成成本。
2. **选择区域**：对当前状态尚未试完的区域按风险排序。普通局部搜索改为固定种子下的随机排列，其余规则相同。
3. **枚举**：所选区域的另外两档按数值升序评价。剩余预算只有一次时只评价一个，并记录截断。
4. **接受**：从当前状态和这次已评价邻居中，按同一比较器选择严格改善的状态；持平时用固定规则。接受后清空该当前状态的区域遍历进度，重新计算风险/排列。
5. **继续**：无改善则标记该区域已尝试，处理下一个，直到找到改动或全部单步邻居已试完。重复状态直接读缓存，不重复生成或消耗新状态预算。
6. **重启**：完整邻域无严格改善时，最多2次随机重启。采样和评价计入总预算，使用独立登记的重启随机流，普通/风险方法共用种子规则。重启可从不可行状态开始，但不覆盖最佳可行档案。
7. **终止**：预算耗尽、重启耗尽、无新状态或用户取消时返回最佳可行结果与原因。控制对已见状态的重复采样，有限空间接近耗尽时仍应终止。

工程起点：总预算40个不同状态，包含默认、邻居与重启起点。实际重启点可能因轨迹不同而不同，应记录；不能宣称不同方法轨迹完全配对。建议画10/20/40状态检查点曲线；提前停止时如实注明实际数量，不伪造新增评价。

## 6. 基线、消融与实验矩阵

| 实验轴 | 比较条件 | 必须固定 | 回答的问题 |
|---|---|---|---|
| 全局强度取舍 | 扫描全局α，至少含0.3/0.6/0.9并补中间档 | 同生成器、图对、预处理与评分 | 是否简单全局调强度已能达到相同取舍 |
| 区域表示 | 固定网格 vs 自适应区域 | 同普通局部搜索器、损失/约束、预算、种子；尽量匹配N | 内容划分是否优于不看内容的划分 |
| 关系约束 | 外观加权、等权、λ=0 | 同自适应区域、搜索器、起点、预算 | 外观关系是否比一般协调或无协调有用 |
| 搜索策略 | 风险引导、普通局部、随机状态 | 同区域、Q/T/S/J、起点、预算和缓存规则 | 启发式是否提高预算利用率 |
| 工程效率 | M4提供的编码缓存对照 | 同候选状态、模型、输出与硬件 | 省下哪些计算，增加多少内存 |

随机状态搜索均匀抽取未见离散状态，默认状态同样计入预算并保留可行档案；它没有局部重启含义。普通局部与风险引导只有变量顺序不同，不能给主方法更多重启或更宽风格上限。

全局扫描枚举值先写入配置；报告真实评价次数，不假装它也是40次搜索。图、λ或表示改变时重新计算对应状态的S/J，绝不跨方法误用状态结果缓存。全组可共享规则一致的只读图对特征，状态评价缓存每方法独立。

若试运行成本过高，由小组冻结一个覆盖两个研究问题的最小实验矩阵；额外敏感性分析明确标为补充。不得只运行主方法和随机搜索，就宣称已经证明风险排序的作用。

## 7. 客观评价与统计规则

正式任务是M4清单里的18个图对，不手工挑成功图。试运行的3张内容图不进入正式汇总。

| 维度 | 记录和报告 |
|---|---|
| 内容/风格取舍 | Q、T原值与相对默认变化；结构-风格散点/曲线；在可比风格范围讨论结构收益 |
| 搜索效率 | 不同状态数对应的最佳可行J，同时列Q/T与实际墙钟时间 |
| 结构复核 | 固定边缘提取与像素容差的轮廓匹配精确率、召回率、F1；无边缘情形规则明确 |
| 运行资源 | 分区、准备特征、单次解码、评分、完整搜索、导出耗时；实际RSS/显存口径 |
| 稳定性与失败 | 各图对改善/未改善、可行状态比例、预算/重启、失败原因和默认回退 |

建议随机条件使用5个事先登记种子。先在图对内总结种子波动，再按内容图聚合两种风格；同时保留逐图对明细。18个图对共享9张内容和2种风格，不把每个候选或种子当作独立数据样本。

时间与资源和M4统一：相同硬件、图像尺寸和精度；预热后正式至少5次；GPU正确同步；冷启动、稳态和完整流程分开。质量实验的种子次数不等于性能重复次数。

Q/T是用于优化的代理指标，不能将同一目标下降直接称作全面质量提升；补充轮廓与完整视觉案例，并说明其同样不等于语义/审美真值。不需要人工逐轮选图，人工观感研究属于可选补充。

## 9. 正确性检查

| 检查 | 验收性质 |
|---|---|
| 可控小空间 | 小N有限状态上检查可行性、接受和档案；小空间穷举最优只作验证，不当真实图对已知最优 |
| 默认保底 | 默认状态可行；无改善、取消和预算耗尽仍返回已有最佳可行图 |
| 预算 | 默认计1；缓存命中不加不同状态数；重启起点与新邻居正常计数；不超预算 |
| 局部动作 | 每邻居只改一个变量，不越允许档位；持平不来回循环 |
| 评分口径 | 非有限值明确失败；Gram、Q权重、无边S和零尺度有处理 |
| 风险分摊 | 区域结构贡献和≈Q、协调贡献和≈S；风险并列顺序稳定 |
| 基线公平 | 普通与风险共用比较器、预算和重启实现；只替换选择策略 |
| 缓存隔离 | 图对/区域/目标变化失效；后运行方法不免费复用前一方法候选 |
| 真实集成 | M4实际生成、M5真实RegionPack，完整记录一次真实搜索 |

假评分能证明程序逻辑，不能证明生成效果；跳过真实权重检查不能写成全部测试通过。
