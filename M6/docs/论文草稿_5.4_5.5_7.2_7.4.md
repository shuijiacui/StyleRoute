## 5.4 目标、约束与搜索

在固定生成器（M4 的 AdaIN 编解码流水线）上，我们把风格迁移的输出
$I(\boldsymbol\alpha) = G(c, s, \boldsymbol\alpha)$ 表示为按区域分组的
强度向量 $\boldsymbol\alpha = (\alpha_1, \dots, \alpha_N)$ 的函数，
其中 $\alpha_i \in \{0.3, 0.6, 0.9\}$，$N$ 为内容划分区域数。
$G$ 内部保证：编码器只运行一次，改变 $\boldsymbol\alpha$ 只触发一次解码。

### 5.4.1 独立评价器

评价使用一套**与生成器完全分离**的冻结网络：torchvision 官方
ImageNet 预训练 VGG19（权重版本 IMAGENET1K_V1，指纹
`a386708afae81fa0`），冻结、$\mathrm{eval}$ 模式、无梯度，输入采用
ImageNet 标准化（与生成器使用的 AdaIN 编码器归一化不同，二者不共享
任何参数与预处理）。每层激活记为 $\phi_l(I)$。

**结构代理 Q。** 在 relu3_1 层，生成图与内容图逐位置通道均方差为

$$d(p) = \frac{1}{C}\sum_{k=1}^{C}\bigl(\phi_{3}(I)(p,k) - \phi_{3}(c)(p,k)\bigr)^2,$$

由**原内容图**梯度幅值（3×3 Sobel + 盒平滑）构造有界非负权重

$$b(p) \in [b_{\min}, b_{\max}] = [0.1, 1.0],$$

加权得

$$Q = \frac{\sum_p b(p)\,d(p)}{\sum_p b(p)}.$$

$b(p)$ 只依赖内容图，与候选无关，因此每个图对只计算一次。

**风格统计 T。** 对 relu1_1 至 relu4_1 四层，计算归一化 Gram 矩阵
$G_l(F) = FF^{\top}/(C_l H_l W_l)$（$F$ 为该层激活），与**固定不变**的
风格参考图 Gram 逐层 MSE 后等权平均：

$$T = \frac{1}{4}\sum_{l \in \{1_1,2_1,3_1,4_1\}} \mathrm{MSE}\bigl(G_l(\phi_l(I)),\, G_l(\phi_l(s))\bigr).$$

**协调项 S 与目标 J。** 区域邻接图（M5 提供）的边集 $E$ 带权重
$w_{ij}$，定义

$$S = \frac{\sum_{(i,j)\in E} w_{ij}(\alpha_i - \alpha_j)^2}{\sum_{(i,j)\in E} w_{ij}},$$

无边时 $S=0$。搜索目标与归一化默认参考（$\boldsymbol\alpha_0$
全 0.6，其得分记 $Q_0, T_0$）为

$$J = \frac{Q}{Q_0 + \delta} + \lambda S, \qquad \delta = 10^{-3},\ \lambda = 1.$$

**可行性约束。** $T \le (1+\varepsilon)T_0$，$\varepsilon = 0.05$；
超限量 $\mathrm{violation} = \max(0, (T-(1+\varepsilon)T_0)/(T_0+\delta_T))$，
$\delta_T = 10^{-6}$。

**比较器（冻结）。** 可行状态恒优于不可行状态；不可行状态先按
超限量、再按 J 排序；可行状态按 J 排序。只有排序胜出且幅度超过
容差 $10^{-9}$ 的**严格改善**才被接受，平局不循环。非有限分数记为
显式失败，绝不进入档案。

### 5.4.2 风险引导的约束局部搜索

单变量邻域：每次只改变一个区域的强度，枚举其余两档（升序）。
变量排序依据**区域风险**

$$\mathrm{risk}_i = \frac{q_i}{Q_0+\delta} + \lambda s_i,$$

其中结构贡献 $q_i$ 按区域软权重在空间上分摊 $Q$（满足
$\sum_i q_i = Q$），协调贡献 $s_i$ 将每条边的代价对半分给两端
（满足 $\sum_i s_i = S$）。风险按降序排列，并列按区域编号。

搜索从默认状态 $\boldsymbol\alpha_0$（计第 1 次评价）出发：按风险序
遍历未尝试区域、评价其两个邻域状态，若当前加邻域中存在严格改善则
接受最优者并清空进度；否则标记该区域。全部区域均无改善时进行至多
$r_{\max}=2$ 次**随机重启**（均匀抽样未见状态作为新起点），随后停止。
已评价状态按离散档位索引元组建缓存，重复状态读缓存、不计预算。
总预算 40 次真实评价（默认状态计 1）。任何终止条件下都返回可行
档案中 J 最优的状态；若无改善则如实回退默认图并标记
`used_default`，绝不挑选"看起来好"的结果。

```text
算法 1  风险引导约束局部搜索
输入: 生成器 G, 评价器 (Q, T), 区域包 R, 预算 B=40, 重启上限 r_max=2
1:  α ← (0.6, …, 0.6); 档案 A ← {α};  (评价 #1)
2:  tried ← ∅
3:  while 预算剩余 do
4:      for i ∈ 区域, 按 risk_i 降序, i ∉ tried do
5:          for a ∈ {0.3, 0.9} 升序且预算足够 do
6:              评价 α[i←a]（缓存命中不耗预算）
7:          if ∃ 严格改善 then 接受最优者; tried ← ∅; 更新 A; break
8:          else tried ← tried ∪ {i}
9:      if tried = 全部区域 then
10:         if 已重启 r_max 次 then break
11:         else α ← 均匀抽样未见状态; tried ← ∅; 重启计数 +1
12: return 档案 A 中 J 最优的可行状态（或默认状态）
```

该方法是**约束局部优化**：风险排序是待检验的项目启发式（5.5/7.2），
我们不冒称 Min-Conflicts、A* 等标准算法。

| 参数 | 值 | 冻结依据 |
|---|---|---|
| 强度档位 | {0.3, 0.6, 0.9} | pilot 检查可行率与区分度 |

### 7.2.2 图对级分布

以图对为统计单位（5 种子平均后，72 对）：

| 方法 | 均值 J/J0 | 中位数 | 最小值 | 改善图对数 |
|---|---|---|---|---|
| 风险引导 | **0.99324** | 1.00000 | **0.95200** | **34/72** |
| 普通局部 | 0.99487 | 1.00000 | 0.97415 | 34/72 |
| 随机采样 | 1.00000 | 1.00000 | 1.00000 | 0/72 |
| 全局扫描 | 1.00000 | 1.00000 | 1.00000 | 0/72 |

三个事实必须同时报告：

1. **改善是真实但选择性的**。局部搜索在约半数图对（47%）上把内容
   结构保留推到默认状态之下（Q/Q0 最低 0.952），改善幅度随图对差异
   很大；随机采样与全局扫描在全部 720 次运行中**没有一次**产生可
   交付改善。
2. **多数图对上没有任何方法优于默认**。中位数为 1.00000 说明对
   于 38/72 的图对，默认的均匀 0.6 已经是该搜索域内的强基线——
   这不是失败，而是"何时值得搜索"的边界信息；归因分析见 7.2.3。
3. **风险排序的价值体现在深端**。风险引导与普通局部的均值差在
   evaluation 上稳定存在（@40 差 0.0016，图对级均值差 0.0016），且
   风险引导的最深改善（0.952）明显超过普通局部（0.974）；pilot 上
   二者几乎无差（0.99794 vs 0.99795），说明该优势需要大样本才显现。

**种子波动（README §7 统计口径）。** 以图对内 5 种子 J 的标准差度量：
风险引导方法在 72 图对上**全部为 0**——其风险排序路径是确定性的，
重启（260/360 个 run 触发 1 次）只改变失败轨迹的探索过程，不改变
最终档案（失败时各种子都如实回退默认图，J 恒等于 J0）。普通局部
的变量随机排列在约 6 个 beach/downtown 图对上引入小波动
（图对内 SD 最大 0.011，全部图对均值 0.002）。因此主文以图对为
统计单位、种子作预登记重复的口径下，种子波动不改变任何结论；
它同时说明风险排序在该矩阵上几乎是完全确定的（轨迹级随机性
不影响结果级可复现性）。

### 7.2.3 失败案例归因

38/72 图对上风险与普通两种方法均未超越默认（5 种子均值口径）。
对全部失败图对按冻结规则自动归因（`M6/analysis/failure_analysis.py`，
原始轨迹重放，不重新搜索）：

| 类别 | 规则 | 图对数 |
|---|---|---|
| s_blocking（S 惩罚阻挡） | 存在 Q<Q0 但 J≥J0 的可行邻居 | 36 |
| t_binding（T 约束顶死） | 不可行评价占比 ≥ 25% | 2 |
| flat（地形平坦） | 可行邻居 Q/Q0 极差 < 0.005 | 0 |
| missed（搜索未命中） | 其余 | 0 |

两个结构性结论：

1. **失败几乎全是目标权衡问题，不是搜索失误**。36/38 的失败图对上，
   搜索确实访问过 Q 低于默认的可行邻居，但单区域移动引入的协调代价
   S 吃掉了 Q 的收益（J 未低于 J0）；而"有改善空间但搜索没找到"
   （missed）为 0——40 预算 + 2 重启在这些小空间上没有遗漏。这直接
   引出 λ=0 消融（§7.4）：若去掉 S 项，这些被阻挡的状态能否转为
   实际改善。
2. **T 约束很少是瓶颈**（仅 2/38），ε=5% 的可行域在这些图对上是
   宽松的；内容结构贡献在空间上分散（默认状态 top-4 区域仅占 q 的
   约 40%–50%），固定网格下不存在"一个主导区域"，这是区域搜索改善
   幅度天然有限的结构性原因。

### 7.2.5 区域表示对照（固定网格 vs 内容自适应）

同一搜索器/预算/种子下，仅替换 RegionPack 来源（固定网格 N=16；
M5 SLIC 自适应 N∈[6,16]，均值 10.6）。结果（72 图对，5 种子均值
后再按图对统计）：

| 方法 | 区域表示 | 改善图对 | J/J0 均值 | J/J0 最小 | Q/Q0 均值 |
|---|---|---|---|---|---|
| 风险引导 | 固定网格 | **34/72** | **0.99315** | 0.95187 | **0.9853** |
| 风险引导 | 内容自适应 | 25/72 | 0.99595 | **0.94260** | 0.9902 |
| 普通局部 | 固定网格 | **34/72** | **0.99478** | 0.97402 | **0.9871** |
| 普通局部 | 内容自适应 | 26/72 | 0.99637 | **0.95537** | 0.9911 |

逐对比较（风险方法）：自适应更优 10 对、网格更优 26 对、持平 36 对。

**这是一个需要如实报告的负面结果**：在该生成器与评分器组合下，
内容自适应分区没有带来净收益，改善图对数与平均深度均低于均匀
网格；但自适应条件下的**单对最深改善更深**（0.9426 vs 0.9519），
且与 N 无单调关系（N=13 的 4 对全部改善、N=15 的 8 对仅 12%）。
我们给出的解释（标注为分析而非结论）：(1) SLIC 区域贴合内容边界，
恰好把大块同质区（天空、海面）整体划为单区，而这些区域对
结构代理 Q 的梯度权重低——搜索拿到的"精确控制"主要落在
对 Q 不敏感的变量上；(2) 自适应区域尺寸不一，风险分摊按掩码质量
加权，大区域主导排序，等尺寸网格的变量权重天然均衡；(3) 区域数
偏少（均值 10.6 < 16）压缩了搜索空间。该结果把"区域表示"从
默认假设变成有条件的实验问题：自适应的价值可能要在更强评分器
或语义区域（而非颜色同质区域）上才能兑现。

## 7.4 综合分析

结合 M4（生成器）、M5（区域表示）与本章结果，对两个研究问题的
回答如下（两个区域表示条件均已完成）：

**RQ1：区域级控制是否优于全局强度调整？** 是。在同一生成器与同一
预算口径下，全局强度扫描在 72 图对上没有任何可交付改善，而局部
区域搜索在 47% 图对上改善了内容结构保留（Q/Q0 最低 0.952）。配合
Q/T 散点（`qt_scatter`）可见：全局调整只能沿"风格化强度"单轴移动，
无法抵达区域级组合才能到达的低 Q 区域；约束 T ≤ 1.05·T0 恰好拦截
了风格化失控的散乱状态（违反样本集中于高 T 侧），说明可行性约束
在保住风格底线的同时为结构保留腾出了空间。

**RQ1b：内容自适应分区是否优于均匀网格？** 在本组合下**否**
（7.2.5）：自适应条件改善图对更少（25 vs 34）、平均深度更浅，
仅在单对最深改善上更深。我们将此报告为边界条件而非失败：
内容对齐的颜色同质区域恰好是结构代理不敏感的变量，且区域尺寸
不均破坏了风险排序的权重均衡。该发现的价值在于否定了"自适应
必然更好"的默认假设，并把后续方向指向语义区域或更强评分器。

**RQ2：风险引导是否提高了预算利用率？** 温和但一致的肯定。相对
普通局部搜索（唯一差别是变量排序策略），风险引导在全部检查点与
图对级均值上稳定更优，且深改善更多；但其优势量级（约 0.16% 的
J/J0）不大，且二者中位数相同（多数图对无改善）。因此我们**收缩**
对该启发式的表述：风险排序不是决定性的，但在预算受限、需要挖深
改善的场景下提供了稳定的小幅增益；论文中同时给出分布而非仅均值。

**轮廓补充指标（1440 runs 已全量评估）。** 以固定 Sobel 提取 +
2px Chamfer 匹配的轮廓 P/R/F1（双空=1.0、单空=0.0）作为与优化目标
独立的补充指标：默认状态图对级 F1 均值为 0.6889；风险引导搜索相对
默认平均仅 **+0.0032**（最深 +0.0305，个别图对 -0.0116），在 25/72
图对上有所提高；普通局部 +0.0036（29/72 图对）。风险 run 内
corr(Q/Q0, ΔF1) = **-0.29**（n=360）：内容保留越深的输出轮廓一致性
倾向越好，但相关强度有限。结论：搜索优化的 Q/T/S 代理确实转化为
轮廓层面的轻微改善，但**幅度远小于 J 的降幅**——轮廓是风格化输出
的天然强项，区分度主要来自纹理/结构细部而非边缘有无；因此轮廓
指标适合作为"无恶化"的护栏证据，不宜作为主效果的宣传口径。

**关系约束消融（λ=0）。** 与主矩阵只相差 λ 一个参数（72 图对 × 风险/
普通 × 5 种子 = 720 runs，固定网格）。注意 λ 改变后 J 的含义随之改变，
按 README 口径**不直接用各自 J 互比**，而比较共同的 Q/T 与协调代价：

| 指标（风险方法，图对级 5 种子均值） | λ=1（主） | λ=0（消融） |
|---|---|---|
| 有改善图对数 | 34/72 | **72/72** |
| 图对级 J/J0 均值 | 0.9932 | 0.9797 |
| Q/Q0 均值 | 0.9853 | **0.9798**（57/72 对更深） |
| 最终状态 S 均值 / 最大 | 0.008 / 0.038 | **0.032 / 0.079**（约 4 倍） |

7.2.3 的归因得到完全验证：36/38 失败图对（s_blocking）在 λ=0 下
**全部**释放出改善。结论有两面：(1) 协调项确实是这些图对上改善的
主要阻挡，去掉它内容保留全面变深；(2) 代价是相邻区域强度差异
约 4 倍（S 0.008→0.032），输出风格化在空间上更"碎"。因此 λ 是
真实的设计权衡而不是可以省略的点缀——偏好平滑过渡的视觉场景应
保留 λ=1（改善少但均匀），偏好内容保真的场景可考虑 λ=0（或更小
λ），该对比已在 5.5 标注为补充实验。

**局限与边界。** (1) 自适应区域结果为负面（7.2.5），但仅检验了
SLIC 颜色同质分区一种实现；语义区域或其他分区策略是否不同，
超出本文范围；(2) 约半数图对上默认状态即最优，
说明该方法的适用面有限，实际部署应先用默认结果做基线对照；
(3) 评价网络为 ImageNet VGG19，Q/T 是代理指标而非感知指标；
上文的轮廓 F1 补充结果显示代理指标的改善只部分转化为感知可查的
边缘一致性变化；(4) 预算 40 是冻结的工程选择，更大预算的边际收益
未检验。
