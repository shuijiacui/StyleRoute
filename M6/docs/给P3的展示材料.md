## 二、核心数字卡片（PPT 直接引用）

- 正式矩阵：**72 图对 × 4 方法 × 5 种子 = 1440 runs**（统计单位是图对，种子是预登记重复）
- 风险引导 @40：**J/J0 = 0.99327**（n=360 图对-种子），普通局部 0.99491，随机采样与全局扫描 **1.00000（零改善）**
- 图对级：**34/72 图对**有改善（两种局部方法各 47%），风险方法最深 **0.952**
- 预算诚实：默认图计 1 次评价，缓存命中不耗预算，全局扫描只报真实 5 次
- 成本：单次解码 0.11s、单次评分 0.43s、完整搜索 18.9s（CPU）、峰值内存 < 1 GB
- 轮廓护栏 F1：默认 0.689 → 风险 0.692（+0.003），证明优化没有牺牲边缘一致性

## 三、每张图的读法

### 1. search_curves.png（搜索曲线，主图之一）

- 纵轴：可行档案中最佳 J 相对默认 J0 的比值（**越低越好**，1.0 = 没打过默认）
- 横轴：真实评价次数（10/20/40 检查点）
- 读法：红线（风险）全程最低且到 40 次还在降 → 预算用得值、重启机制有效；
  随机采样（绿）贴平 1.0 → 瞎试 40 次一次都没成功；全局扫描（灰）只有 5 个点
  （它只做了 5 次真实评价，我们没假装它也是 40 次搜索）
- 注意：曲线族有单 run 细线 + 方法均值粗线，均值以图对为单位

### 2. qt_scatter.png（Q/T 散点，主图之一）

- 横轴 Q/Q0（内容结构保留，<1 更好），纵轴 T/T0（风格统计偏离，>1.05 = 违反约束）
- 读法：灰虚线是可行性边界 T/T0=1.05；**违反的点（空心）集中在高 T 侧**，
  说明约束真在干活；红（风险）比蓝（普通）更往左下钻 → 区域级组合能到达
  全局调强度到不了的低 Q 区域——这是"区域控制值得"的核心证据

### 3. compare_beach_04__met_436535.png（视觉案例，必选）

- 四联：内容 | 风格（梵高麦田） | 默认 0.6 | 搜索最佳（J=0.952，全矩阵最深改善）
- 读法：默认图天空被整块风格化涂抹；搜索最佳的天空保留了更多照片原有的
  蓝色层次，海面纹理也更接近内容图——改善在**纹理细部**，缩略图差异不大
  是正常现象（可放大讲）； Van Gogh 风格的山体、柏树区域保持风格化
- 讲法："我们没有换生成器，只调了 16 个区域各自的风格化强度，
  就找到了更接近原照片质感的平衡点"

### 5. 失败归因（口述 + 一张小表，不必放图）

- 38/72 图对无改善；归因：**36/38 是"S 惩罚阻挡"**——搜到了 Q 更低的邻居，
  但协调代价吃掉了收益；仅 2 个是 T 约束顶死；**搜索失误为 0**
- 话术："失败不是搜索笨，而是目标本身在这些图对上权衡不出净收益——
  这正好是 λ 消融（无协调项对照）要回答的问题"

## 四、诚实话术速查（被追问时用）

| 追问 | 回答 |
|---|---|
| "为什么中位数是 1.0？" | 多数图对上默认 0.6 就是强基线，改善是选择性的（47% 图对）——我们如实报告分布，不只报均值 |
| "风险排序提升多大？" | 均值约 0.16% J/J0，小而稳定；深改善更多（最深 0.952 vs 普通 0.974）。我们收缩表述：稳定的小幅增益，不是决定性优势 |
| "全局调强度不行吗？" | 不行：720 次全局扫描/随机采样零改善；Q/T 散点显示全局只能沿单轴移动，到不了区域组合的低 Q 区 |
| "Q/T 是质量吗？" | 是 ImageNet VGG19 的代理指标，不等于感知真值；我们用独立轮廓 F1 做了护栏核查（无恶化），并如实报告其局限 |
| "搜索是最优解吗？" | 不是。40 预算的约束局部优化 + 2 次重启，无最优性保证；"未命中"类失败为 0 说明预算在这些小空间够用 |
| "协调项 S 有什么用？" | 消融显示：去掉 S 后 36/38 失败图对全部释放出改善（Q 更深），但相邻区域强度差约 4 倍、输出更碎——λ 是平滑 vs 保真的真实权衡，不是摆设 |
| "自适应分区不是更好吗？" | 实测否：SLIC 自适应条件改善对 25 vs 网格 34，逐对 10 胜 26 负——内容对齐区域恰好是结构代理不敏感的变量；这是有价值的负面结果，说明区域表示是实验问题而非默认假设 |
| "可复现吗？" | 风险方法结果级零方差（确定性排序）；全部图表由原始日志脚本重新生成 |
