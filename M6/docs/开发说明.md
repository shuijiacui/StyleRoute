## 当前状态

Phase A/B 骨架已完成并通过测试（28 个）：

- `M6/search/solver.py` — 纯 Python 搜索核心：状态缓存（离散档位索引作键）、
  预算（默认 40，默认状态计 1）、可行档案、严格改善接受（冻结容差）、
  最多 2 次随机重启、保底回退。风险引导 / 普通局部 / 随机状态三种模式
  共用同一引擎，只换变量选择策略。
- `M6/search/baselines.py` — `run_risk_guided` / `run_plain_local` /
  `run_random_states` / `run_global_scan`（全局扫描报告真实评价数，
  域外强度不进正式档案）。
- `M6/search/objective.py` — 真实评分器：独立 torchvision VGG19
  （ImageNet 归一化，与 M4 AdaIN 编码器分离）、Q（relu3_1 + 内容梯度
  有界权重 b(p)）、T（relu1_1..4_1 归一化 Gram MSE）、S/J、可行性
  `T ≤ (1+ε)T0`、区域风险分摊（Σq_i≈Q、Σs_i≈S）。torch 缺失时仍可
  导入纯数学部分（协调项、J 组装）。
- `M6/search/adapter.py` — `team.json` 注册的 `solve` 入口；默认图复用
  不重复解码，`decoder_calls = 1 + 实际 generate 次数`，完整 metadata
  （权重指纹、q0/t0、预算、种子、stop_reason）。
- `M6/regions_grid.py` — 固定网格 RegionPack stub（`metadata.stub=True`），
  开发期替代 M5，同时也是实验矩阵"固定网格 vs 自适应区域"的基线条件。
- `M6/tests/` — Phase A 假评分测试（20 个，纯逻辑）+ 真实集成测试
  （8 个，torch + `src.integration.validate_search_result`）。

  "逻辑测试"与"真实权重集成测试"（README §9）。

## Pilot 结果与参数冻结（2026-11-22，正式）

矩阵：12 图对 × 4 方法 × 5 种子 = 240 runs，全部完成（CPU，每 run 约 18s/40 解码）。
区域表示为 4×4 固定网格（M5 未落地，stub 条件）。

主要发现（n=12 图对，图对为统计单位）：
- 局部搜索优于默认：risk 27% / plain 27% 的 run 有改善；随机状态 0/60。
- 全局扫描在其搜索域内从未优于默认 0.6（返回 used_default），且全局 α 的调整
  无法触及区域级别的改善——支持"区域控制值得"的研究方向。
- risk 与 plain 差距很小（@40 均值 J/J0: 0.99794 vs 0.99812），风险排序的相对
  优势在 pilot 上不显著，evaluation 上需如实报告。
- eps=5% 可行率约 92%，约束有区分度但不滥；lambda=1 下 S 占 J 比重可观。
- 检查点显示改善持续到预算末尾（重启在起作用），40 预算合理。

冻结值（evaluation 必须沿用）：levels=(0.3,0.6,0.9)，budget=40，max_restarts=2，
seeds=(0,1,2,3,4)，eps=0.05，lam=1.0，delta=1e-3，delta_t=1e-6，tolerance=1e-9。

遗留说明：
- global_scan 汇总曲线中的 0.99869 来自域外强度状态（0.5/0.7）的可行低 J——
  它们被如实评价记录，但不能作为结果返回（M4 校验器会拒绝），故其
  status 全为 no_improvement。论文中需区分"评价过的低 J 域外点"与"可交付结果"。
- beach_01__met_436535 的 risk/plain 汇总行系从轨迹重建（elapsed_s 记 0），
  不影响 J/Q/T 统计。
- 待 M5 落地后补"自适应区域"条件并重跑矩阵（当前全部结果 = 固定网格条件）。
