# 项目目录说明

根目录现在按五类组织，常用启动命令保持 `python -m streamlit run app.py`。

| 主目录 | 内容 | 什么时候看 |
|---|---|---|
| `src/` | 页面、模型、接口、排版、性能测量及开发工具 | 写代码、接 M5/M6、运行工具 |
| `resources/` | 输入图片、权重、字体、配置、依赖文件及上游参考 | 换图片、查权重、改配置、安装依赖 |
| `docs/` | 原方案、来源、接口、验收与论文材料 | 阅读说明、联调、准备报告 |
| `tests/` | 自动测试与明确标记的测试替身 | 验证实现 |
| `outputs/` | 运行结果、日志、样例、ZIP 与缓存 | 查看生成图、找证据、提交文件 |

## 源码内部

```text
src/
├── app.py              实际页面
├── contracts.py        M4/M5/M6 数据结构
├── integration.py      外部模块调用
├── outputs.py          运行文件与来源保存
├── project.py          项目路径、配置与版本工具
├── models/             预处理、AdaIN、区域融合、生成 CLI
├── postcard/           中文明信片排版
├── bench/              性能测量
└── tools/              下载、数据登记、验证、诊断与打包
```

单独运行M4时默认适配器位置为`src/regions/`、`src/search/`；GitHub团队协作时M5/M6继续在同级`StyleRoute/M5`、`StyleRoute/M6`开发，用`resources/configs/team.json`接入。共享结构统一`from src.contracts import ...`，不要复制类型；启动目录与PYTHONPATH设置见`交接总览.md`。

## 资源内部

```text
resources/
├── images/             content、styles、清单、元数据和图片图库
├── weights/            两份模型权重及来源指纹
├── fonts/              中文字体及 OFL 许可
├── configs/            default.json 基线、creative.json 创作配置
├── env/                requirements、开发依赖和实际锁定版本
└── upstream/adain/     原始网络参考、统计函数和 MIT 许可
```

原始图片、权重、字体、上游参考及最初方案的 33 份关键文件，在移动前后检查了 SHA256，字节保持一致。移动审计记录为 `outputs/reorganization/layout.json`。

## 常用命令

在项目根目录执行：

```powershell
# 启动页面
.\.venv\Scripts\python.exe -m streamlit run app.py

# 运行测试
.\.venv\Scripts\python.exe -m pytest tests -q

# 核验图片
.\.venv\Scripts\python.exe -m src.tools.prepare_data

# 准备权重与字体（已有文件时核验）
node src/tools/download_assets.mjs

# 生成交付包
.\.venv\Scripts\python.exe -m src.tools.package_submission
```

命令行生成改为 `python -m src.models.cli`，性能测量改为 `python -m src.bench.profile`；参数示例见根目录 README。
