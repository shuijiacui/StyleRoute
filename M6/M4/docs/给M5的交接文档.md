## 2. M4 传给你的输入

| 参数 | 实际内容 | 必须遵守 |
|---|---|---|
| `content_rgb` | PIL `RGB`，已按EXIF旋转、透明白底合成、保持比例缩放并中心裁剪 | 在这张图上分区；不要读原文件后重新裁剪，也不要原地修改输入 |
| `feature_hw` | `(Hf,Wf)`，当前基线通常32×32 | 使用真实传入值；512创作输入通常64×64，不能写死32 |
| `device` | `torch.device`，来自生成器实际设备 | 输出掩码放到同设备，FP32，不根据本机GPU存在与否自行决定 |

内容图基线是256×256，`PIL.size` 顺序为(W,H)。数组/张量形状按(H,W)。输入颜色范围：PIL转换成 NumPy 后通常uint8[0,255]，进入Lab/梯度算法前显式固定转换流程。

## 3. 你返回的 RegionPack

唯一共享定义在 [src/contracts.py](../src/contracts.py)。

| 字段 | 类型与约定 |
|---|---|
| `region_ids` | `tuple[int, ...]`，必须恰好为`tuple(range(N))`，N≥1 |
| `labels` | NumPy整数数组`[H,W]`，形状等于处理后内容图，恰好出现全部0…N−1 |
| `soft_masks` | torch.float32 `[N,Hf,Wf]`，同设备，非负、有限；每点沿N求和为1，`atol=1e-5, rtol=0` |
| `edges` | `tuple[(i,j,w), ...]`，三方统一每条无向边只存一次且i<j，权重有限非负 |
| `metadata` | JSON可序列化dict，记录算法、参数、配置指纹、实际N、节点统计与构造信息 |

硬标签与软掩码各区域的总权重都必须非零。若某区下采样后消失，回到分区/合并阶段处理并同步重建编号、边和统计；M4不会静默删区或自动归一化错误输入。软掩码是参与融合的权重，并非一定互斥的二值矩阵。

M4校验编号、形状、dtype/device、覆盖、有效区域和边索引/有限权重；**真实邻接、连通性、边去重和边权方向仍由M5测试证明**。建议metadata至少包含：

```python
metadata = {
    "algorithm": "实际算法名称与版本",
    "config": {},                 # 真实冻结参数，不省略默认值
    "config_sha256": "实际配置指纹",
    "region_count": N,
    "adjacency": "4-neighbor; one undirected edge with i < j",
    "mask_interpolation": "实际插值/平滑/归一化次序",
    "nodes": [],                  # 每项region_id、面积、质心等，按编号对齐
    "coverage_max_abs_error": measured_error,
}
```

上面是字段说明，不是已经测得的数据。NumPy标量/数组和torch张量先转换为Python标量/列表再放metadata；大体积图和掩码单独保存，不塞进JSON。

## 4. 可以立刻执行的 M4 调用

下面从 `StyleRoute/M4` 执行，先按总览设置 `PYTHONPATH` 为仓库根目录；`M5.regions.adapter` 需已实现。

```python
import torch
from M5.regions.adapter import build_regions
from src.models.adain import AdaINEngine
from src.project import load_config, project_path

engine = AdaINEngine(load_config("resources/configs/team.json"))
pair = engine.prepare(
    project_path("resources/images/content/pilot/mountain/mountain_01.jpg"),
    project_path("resources/images/styles/met_436535.jpg"),
)
regions = build_regions(pair.content_rgb, feature_hw=pair.feature_hw, device=engine.device)
prepared = engine.prepare_regions(pair, regions)  # 校验并复制一次掩码
default = engine.render_global(pair, 0.6)
uniform = engine.render_regions(pair, prepared, (0.6,) * len(regions.region_ids))
torch.testing.assert_close(default.image_rgb, uniform.image_rgb, rtol=1e-5, atol=1e-6)
```

完整单图接口检查命令：

```powershell
.\.venv\Scripts\python.exe -m src.tools.check_handoff --m5-only
```

检查真实适配器返回值、全0.6等价性、重复候选一致性、候选不重新编码和缓存不被污染。成功后写入 `outputs/runs/handoff_时间戳/`，含分区叠加图、输入来源和 `handoff_checks.json`。没有M5时会明确报错，不会替换成网格。这个检查通过也不能替代分区质量或邻接语义测试。

### 离线 NPZ 交接

暂时不走Python适配器时，可提供 `labels`、`soft_masks`、`region_ids`、可选`edges` 的NPZ：

```python
import numpy as np
np.savez_compressed(
    "regions.npz", labels=regions.labels,
    soft_masks=regions.soft_masks.detach().cpu().numpy(),
    region_ids=np.asarray(regions.region_ids, dtype=np.int64),
    edges=np.asarray(regions.edges, dtype=np.float64).reshape(-1, 3),
)
```

```powershell
.\.venv\Scripts\python.exe -m src.models.cli --content resources/images/content/pilot/mountain/mountain_01.jpg --style resources/images/styles/met_436535.jpg --regions regions.npz --alphas "0.3,0.9" --output outputs/runs/m5_npz_check/default.png
```

示例的两个强度只适用于N=2，实际替换为与你的N一一对应的长度；NPZ必须来自这张内容图的同一预处理尺寸。NPZ之外另附配置与来源JSON，CLI不会从NPZ推断算法版本。该路径是手动区域生成检查，不执行M6搜索。
