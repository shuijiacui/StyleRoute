## 选图规则与实验边界

图片在任何模型效果评价之前按场景相关性、地点、构图和光照变化人工选定。不是随机或代表性抽样；不应将结果外推为对全部自然场景有效。

每类 `01` 只用于试运行，`02` 至 `07` 只用于正式评价。可在试运行图对上调参，正式评价开始后冻结配置并完整报告失败，不根据效果换图。试运行与正式集共用风格参考，因此不能声称验证了未见风格泛化。

海滩与山地仍有水面、植被等共同元素；这里是场景分组，不是像素级语义标注。城市组含较多夜景、黎明剪影、黑白 HDR 和雾雪图像，有意保留困难案例，不是日间/夜间均衡样本。海滩试运行图是沙滩椅阵列，主要测试重复纹理与小区域。需记录相应局限，不能把光照或照片处理差异误解成算法差异。

## 文件尺寸与预处理

Commons 照片采用官方等比例 1280 像素宽 JPEG 缩略图，保留原图下载链接与原始尺寸。The Met 采用官方 `primaryImageSmall` 的 web-large JPEG，下载时逐一确认 `isPublicDomain=true`。未本地裁剪或滤镜处理；部分博物馆参考图带有细窄外框，当前保留该外框，可能影响风格统计。如需去边框，应在正式实验前固定裁剪规则、保存派生图指纹，并对所有方法统一使用。

未来生成时再统一执行内容图比例缩放与中心裁剪至 256×256；风格图保持比例缩放。M5 必须接收同一张处理后的内容图。总览中的裁剪只帮助检查构图，不替代实现 EXIF、颜色与尺寸处理的正式预处理模块。

## 核验和重新获取

下载与清单工具使用 Node.js 20 或以上，无需 npm 包。仅执行核验时不联网：

```powershell
node src/tools/download_images.mjs --verify
```

按已保存清单恢复缺失图片，联网获取并检查 SHA256；远端文件变化会报错，不静默接受：

```powershell
node src/tools/download_images.mjs --restore
```

全新目录中首次根据 selection.json 下载：

```powershell
node src/tools/download_images.mjs --download
```

已有 manifest 时，默认下载命令只核验现有文件，避免覆盖。远端原始元数据将来可能变化，完整复现优先保留本次下载文件和指纹。

在 Windows 上重新执行实际图像解码与总览绘制，然后重建图库：

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File src/tools/make_preview.ps1
node src/tools/make_gallery.mjs
```

## 使用条件

The Met 四张参考图按其 Open Access / CC0 政策登记。Commons 照片包括 CC0、CC BY 和 CC BY-SA，不具有统一许可。保留每张图的作者、文件页面、许可版本和链接；发布图片、修改版或生成样例时按对应许可处理。完整来源见 ATTRIBUTION.md 和 metadata/。

新增图片或修改用途时建立新版本并同步清单，不直接覆盖已用于正式实验的版本。
