## 3. 初始分区与相邻合并

### 3.1 复用现成SLIC组件

起步使用scikit-image的SLIC或SLICO，约64个初始超像素。紧凑度、颜色空间、平滑、连通性与起始标签设置必须显式记录。参数只是试运行起点，不保证每张图恰好得到64区。

图像由RGB转Lab后计算区域颜色信息；浮点范围、颜色转换和梯度计算保持固定。SLIC利用颜色与空间邻近，不保证天空、山、建筑等语义完整。

### 3.2 只合并真实相邻区域

对相邻区域计算Lab颜色差和共享边界上的梯度，归一化后构造合并代价。低颜色差、弱边界优先合并；强边界提高代价。

可按以下公式起步，属于待验证的项目设计：

```text
cost(i,j) = u × normalized_color_difference(i,j)
          + v × normalized_boundary_gradient(i,j)
```

合并后重新计算面积、均值、共享边界及相关边，不能永久使用初始图的旧统计。并列候选按固定区域编号处理，保证可复现。归一化尺度、`u/v`、阈值和停止条件在试运行后冻结；不得用每张正式图的结果反向选择最有利参数。

目标为约8至16个最终区域，但**不能为凑数量越过明显边界**。保留实际数量，数量超出范围时说明原因。极小区域优先与最相近的相邻区域合并；没有安全合并方式时记录限制，不静默删像素或伪造掩码。

## 4. 区域邻接与协调权重

先固定邻接定义，例如共享水平/垂直像素边界，角点接触不计为邻接。节点包括面积、位置和外观统计，边包括共享边界长度、颜色差及边界强度。

协调边权的方向必须与合并代价区别清楚：

```text
w(i,j) = exp[-(u_w × normalized_color_difference(i,j)
             + v_w × normalized_boundary_gradient(i,j))]
```

- 颜色相近、共享边界弱：权重大，M6应更强地惩罚强度差。
- 明显内容边界：权重小，允许使用不同强度。
- 归一化、衰减系数及零尺度处理必须记录；合并与协调可采用不同参数，不能无说明地共用。
- 边权是外观连续性假设，不是“同一物体”的真实标签。软掩码扩展不会额外创建图边，图边仍来自硬区域。

M6使用的协调项为边权加权的强度差平方，并按边权总和归一化。你提供权重与统计；不要在区域模块复制另一份目标函数。

## 5. 特征层软掩码

建议构造顺序：

1. 硬标签转每区域one-hot覆盖。
2. 用固定插值/平滑流程变换到实际特征尺寸；平滑尺度和操作次序明确记录。
3. 确保非负，再沿区域维归一化；零分母必须检查。
4. 检查每区在特征层仍有有效权重，记录有效面积；极小/消失区域交回分区步骤处理后重建。
5. 按根目录合同输出到约定设备和精度，并保留可解释的区域顺序。

软掩码允许边界平滑重叠，但逐位置权重和应为1。不能用过大模糊掩盖错误划分，也不能把完全消失区域随意赋予一片新位置。

M4据此生成强度图，随后整图解码。你不需要逐块生成RGB图，解码器跨区域影响仍可能出现。

**联合验收：所有区域强度都设为0.6时，生成图应与全局0.6一致。** 先查看掩码和，再查强度图和融合特征，最后查输出；不以目测替代数值检查。

## 6. 固定网格与关系消融

网格是实验对照，不是主方法。主方法按内容自适应分区，不能默认退回固定3×3。

| 对照 | 你要提供什么 | 如何避免混淆 |
|---|---|---|
| 固定网格 | 尽量接近实际自适应区域数的矩形网格，输出相同RegionPack | 记录网格行列、实际N及残余数量差；精确匹配不了要说明 |
| 外观加权图 | 正常边权与边统计 | 与等权对照使用同一硬划分、掩码和搜索器 |
| 等权图 | 相同邻接拓扑，所有有效边权设为1 | 不重新划分区域 |
| 无协调项 | 向M6提供同一原始区域与图 | 由M6在目标中令协调权重为0，不删除其他结构造成额外变化 |

区域表示实验先使用同一种普通局部搜索器，避免同时更换分区和搜索策略。网格与自适应区域的目标图不同，不能只凭各自综合J跨表示比较；主要看共同的结构Q、风格T、轮廓指标和实际成本。

## 7. 可视化与失败记录

至少输出：原图叠加硬边界、区域ID、图边及权重说明、软掩码有效覆盖。M6返回强度后，可与M4一起制作强度图与最终图对照。

失败案例包括跨越重要边界、过碎区域、纹理误分、特征层消失、软化后明显混合，以及区域数过大造成搜索成本增加。记录图对/内容ID、配置、实际N、现象与原因；不能只保留好看的划分。

## 8. 正确性与可运行验收

| 检查 | 应满足的性质 |
|---|---|
| 硬覆盖 | 每个像素恰好一个有效ID，面积和为H×W，无空编号 |
| 连通性 | 显式检查区域连通；若允许不连通必须说明，不静默假设对象完整 |
| 邻接 | 在小型人工标签上验证真实相邻边，无自环、重复边或越界ID |
| 权重方向 | 弱外观差/弱边界得到更强协调；范围有限，极端零尺度不产生NaN |
| 合并更新 | 合并后统计、ID、图和掩码同步一致 |
| 软覆盖 | 形状、非负、有限、逐位置和、区域有效覆盖通过 |
| 联合融合 | 全0.6与全局一致，编号同步置换不改变结果 |
| 确定性 | 相同输入与配置结果一致；若库步骤有随机性，显式控制并记录种子 |
| 网格兼容 | 同一M4/M6接口能接网格，不需要另一套生成/搜索实现 |

人工标签用于验证图和掩码逻辑，不作为数据集分割真值。正式数据没有人工标注，不报告未定义的“分割准确率”。
