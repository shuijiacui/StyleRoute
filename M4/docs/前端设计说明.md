# 山海来信 · 界面与信笺设计

本次调整围绕旅行、书信与风景：暖白纸色、墨绿色正文、朱红邮戳。主页面负责选图与风景生成，明信片编辑独立放在模态弹框中。

## 设计参考

- [Paperole · Skyline Montréal postcard](https://www.paperole.com/collections/cartes-postales/products/skyline-montreal)：参考横向风景构图和有书写感的标题层次。
- [Present & Correct · Telegram Card](https://www.presentandcorrect.com/products/telegram-card)：参考复古电报卡的边纹、纸色、分隔线与邮政语汇。

参考仅用于构图研究；页面与导出没有嵌入商品图片，也没有复制原插画。参考截图位于本地 `outputs/runs/ui_redesign/references/`，不纳入提交打包脚本。

## 实际设计

- 顶栏固定在窗口上方，始终显示“山海来信”，点击标题回到创作区。
- 标题采用 Ma Shan Zheng；正文、表单和说明采用 Noto Serif CJK SC。本地提供完整导出字体与网页 WOFF 子集，不依赖 Google Fonts 网络服务。
- 山海画报：左侧大幅完整图像，右侧寄语、留白与圆形朱红邮戳。
- 远方邮笺：航空信封色条、山形装饰邮票、书写横线与虚线分栏。
- 旅途手记：左侧笔记、右侧贴纸相框，用错位留白营造手账感。
- 三种模板统一 1500×1000（3:2）画布。图片等比放入独立区域，不裁掉生成图、不叠文字、不加调色蒙版。

## 交互

1. 选择内容图和风格参考，调整强度，点击“生成风景”。
2. 点击“制作明信片 →”，在弹框内选模板、填标题和寄语。提交输入后即时排版，无需重新运行 AdaIN。
3. 点击“下载这封来信 PNG”获取原始 PNG；预览显示同一份 PNG，由浏览器缩放到窗口宽度。
4. “完成，返回风景”、右上角关闭键或 Esc 均可关闭弹框；再次打开保留草稿。改变输入图或强度后关闭旧预览，需重新生成风景。
5. 正文最多五行，按实际字宽排版。标题过长、字体缺字、正文溢出会明确报错，错误草稿不会保留可下载的旧图。

真实区域搜索仍需 M5/M6 接入；目前按钮在缺少模块时禁用。风格迁移模型、生成分辨率与强度定义保持原逻辑。新版导出耗时不能沿用旧版式的测量值，历史运行记录未改写。

## 代码与验证

- 页面：`src/app.py`；主题与弹框：`src/ui/`；导出排版：`src/postcard/render.py`。
- `tests/test_app.py` 检查弹框、草稿、错误状态和模型调用计数；`tests/test_postcard.py` 检查三种版式的完整图像区域、PNG 尺寸与溢出处理。
- 可选浏览器验证：先启动应用，执行 `python -m src.tools.check_frontend`。该脚本需要额外安装 Playwright（`python -m pip install playwright`），默认使用本机 Edge，无需更改日常 pytest 依赖。
- 浏览器截图与真实下载位于 `outputs/runs/ui_redesign/`。成功完成浏览器检查时写入 `browser_checks.json`，包括桌面、390px 窄屏、弹框关闭、字体加载和下载与预览字节一致性。
- 开发电脑已生成网页字体子集；Git不提交字体二进制。首次克隆或调整字体时，安装开发依赖中的FontTools并运行`python -m src.tools.build_webfonts`；原始字体下载使用`node src/tools/download_design_fonts.mjs`（总资产下载命令也会调用它）。

2026-11-15 验证结果：完整 pytest 45 项通过，Ruff 检查通过。真实 Edge 无头浏览器完成图片生成、弹框编辑、切换模板、下载 PNG、关闭并恢复草稿、Esc 关闭以及 390px 窄屏边界检查；无 JavaScript 页面错误。实际下载文件与预览响应逐字节相同。原始检查记录为 `outputs/runs/ui_redesign/pytest.xml` 和 `browser_checks.json`。
