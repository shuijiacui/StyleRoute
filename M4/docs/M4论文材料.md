# M4 论文写作材料

本文是依据当前代码的写作素材，需并入全组课程模板。真实 M5/M6 算法、正式效果实验和对应结论仍待各负责人补充；不能把本文作为整套方法已完成的证明。

## 5.1 任务与数据

系统接收一张内容照片和一张艺术参考图，输出风格化 RGB 图像与包含中文标题、正文的明信片 PNG。项目不训练新网络，使用配套的预训练 AdaIN 编码器与解码器。

当前内容数据是从 Wikimedia Commons 人工整理的三类实景照片：海滩、山地和城市各七张。每类一张用于开发与试运行，另外六张用于正式评价。四张艺术参考来自 The Met 的公有领域开放图像，分别为梵高、北斋、透纳、德加作品；对象编号和原文标题保存在 manifest。十八张正式内容与四张参考组成七十二个正式图对，三张试运行内容形成十二个试运行图对。

该集合替代了初始方案中的 Places365 抽样，不能在论文中仍称数据来自 Places365。集合按场景、构图和光照变化人工选定，不是随机或代表性抽样；城市类包含较多低光照案例。试运行与正式内容不重叠，但共享艺术参考，因此不能声称测试了未见风格泛化。来源、许可、用途、原始元数据与 SHA256 均被保存。正式评价尚未执行。

内容图按比例缩放并中心裁剪到 256×256；风格参考保持比例，长边缩放至 256，短边不足 32 时拒绝。读取时应用 EXIF 方向、转换 RGB，并在白色背景上处理透明度。生成输入为 FP32、RGB `[0,1]`，遵循 normalized-VGG 配套权重，不额外应用分类 VGG 的 ImageNet 标准化。M5 接收相同的处理后内容图，以保持区域和特征对齐。

## 5.2 AdaIN 与空间融合

编码器由完整上游网络严格加载权重后截断到 relu4_1。默认内容图得到 `[1,512,32,32]` 特征。AdaIN 对各通道的空间均值与标准差进行匹配，方差采用样本修正，标准差为 `sqrt(var + 1e-5)`，与所选移植一致。

记内容特征为 `Fc`，统计匹配后的特征为 `Fa`。全局插值为 `F = alpha * Fa + (1-alpha) * Fc`。对于区域软掩码 `Mi` 和区域强度 `ai`，首先计算空间强度 `A(x,y) = sum_i ai * Mi(x,y)`，然后计算 `F(x,y) = A(x,y)*Fa(x,y) + (1-A(x,y))*Fc(x,y)`。M4 校验掩码有限、非负、覆盖完整且逐位置权重和为一，随后统一解码整张融合特征。

同图对的内容特征和 AdaIN 特征只计算一次，候选之间复用，避免重复编码。该优化不省略候选解码，也不省略 M6 的评分。缓存和准备对象遵守只读约定；融合创建新张量。解码结果统一裁到 `[0,1]`，作为评分、预览和导出的共同图像来源。

所有区域具有相同强度时，按掩码归一化条件，空间强度应为常数，因此区域方法应与全局方法在浮点容差内一致。实际误差、置换与缓存检查见 M4验收记录，不以目测代替数值证据。

AdaIN 和既有空间控制来自相关文献；本实现的工作是复用基础生成器、实现区域参数接口、缓存和应用集成，不宣称首次提出空间插值。

## 6 Implementation 的 M4 部分

代码按模型、预处理、融合、排版、应用、测量和外部集成分层。权重在可信发布来源取得并保存 SHA256，使用 `weights_only=True`、CPU 映射和严格 state_dict 加载，随后设置 eval、冻结参数，并在无梯度上下文运行。

Streamlit 缓存模型资源，在当前会话保存图对、默认结果与搜索结果。输入身份由内容字节、风格字节、配置、权重清单和文件状态共同确定；更换输入使旧结果失效。文字和模板只参与排版缓存，不触发新的特征编码或搜索。下载使用同一份 PNG 字节，并关闭下载触发的页面重跑。

排版模块使用 Pillow 和 Noto Sans CJK SC，提供留白与边框两种固定模板，文字位于图像外。按像素宽度逐字符换行，保留显式换行；超长标题、正文、缺字体或缺字形明确报错。画布尺寸 1200×1060，与模型的 256×256 生成分辨率分开说明。

外部 M5/M6 通过配置中的模块函数接入，输入和返回结构见 src/contracts.py。当前生产模块未提供，应用禁用区域搜索并显示接入状态，不返回模拟优化结果。集成完成后，还需补充 M5/M6 的真实实现说明、状态截图与端到端记录。

## 7.3 运行性能与局限

真实运行环境、逐次数据、汇总表与缓存对照见 M4验收记录.md 和 outputs/runs/profile/profile.json。当前是 CPU FP32 测量，不能描述为 RTX 5070 推理。预热三次、正式重复五次；模型首次构造单列，不混入稳态。计时区分读图预处理、编码缓存、单候选解码、明信片导出与热模型 M4 整体流程。RSS 以 10ms 间隔近似采样，CPU 模式的 CUDA 字段记为不适用。

缓存对照使用同一组 0.3/0.6/0.9 状态，两边均保留同一个已加载模型。优化侧准备一次特征，另一侧对每个状态重新编码；先确认输出一致再比较总成本。数值和倍数应从最终记录引用，不能外推为完整搜索速度，也不能代替 M6 效果实验。

可结合 pilot_grid.jpg 讨论纹理迁移、颜色变化和细小结构平滑；强度 1 的样例说明风格增强可能造成结构失真。由于当前没有正式对照和真实搜索结果，不写“结构保持显著提高”“优于全部基线”等结论。正式论文仍需完整报告七十二图对上的成功、无改善与失败，由 M6/P3 组织实验并交相应技术成员核查。
